# The feedback sheet

Write it before the first arm, from the prompt alone: what you care about in this site, one point a row
(for example: eras first, then albums; it works on a phone; which songs it covers; the tone). Don't change
the points once an arm has started.

In each arm, raise the same points, in whatever form that arm allows: in chat, as notes on the HTML page,
or as answers and notes on the video. After each arm, fill in its column for every point:

- **raised**, and where (for example "raised: in chat, at the review"),
- **covered**: the plan already had it, so there was nothing to raise,
- **missed**: it never came up, or it came up and was lost.

Add a row, marked **new**, for anything you raised that was not on the sheet.
